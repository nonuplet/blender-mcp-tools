# 背景・環境の組み立て

最初に `bjs-conventions` の SKILL.md を読む。シーンの準備がまだなら `bjs-scene-setup` を先に行う。

## 1. 仕様を決める（確認ポイント）

作り始める前に、次の内容をユーザーに確認する。

- 空間の種類と全体の大きさ（m）。プレイヤーやカメラが入れる範囲
- グリッドの単位（例: 1 m や 2 m。床・壁などのモジュールはこの倍数にする）
- 必要なモジュールの一覧（例: `Floor_2m`, `Wall_Straight_2m`, `Wall_Corner`, `Door_Frame`）
- 三角形数の目安（Web 向けの環境全体で数万〜10 万程度が一般的。モバイルも対象なら少なめに）
- 当たり判定が必要なもの、Babylon 側で動かす・クリックするもの
- 照明を Blender で置くか（原則は Babylon 側で置く。下記参照）

## 2. モジュールを作る

1 種類のモジュールを、プロップと同じ手順（`bjs-prop` の 2〜3）で作る。

- 原点はグリッドに合わせやすい位置にする（床タイルは `BOTTOM_CENTER`、壁は底面の中心か角）。
- 寸法はグリッド単位の倍数にし、継ぎ目に隙間や重なりが出ないようにする。
- モジュールの元（オリジナル）は `WIP` に置く。

**確認ポイント**: モジュールごとにスクリーンショットを見せ、了承を得る。

## 3. 配置する

`scripts/linked_duplicates.py` で、元のモジュールのリンク複製（メッシュデータを共有する複製）を並べる。

- リンク複製は glTF でメッシュを共有し、Babylon ではインスタンスとして読み込まれる。同じ形のものを大量に置いても軽い。
- 形を個別に変えたいものだけ、通常の複製（メッシュをコピー）にする。
- 位置はグリッド単位の倍数、回転は Z 軸の 90 度単位を基本にする。
- 複製の名前は `<元の名前>_001` から連番で付く。`NAME_PREFIX` で変更できる。

配置したら `set_view.py`（`TOP` と `ISO`）でスクリーンショットを撮る。

**確認ポイント**: レイアウトの了承を得る。

## 4. 当たり判定用のメッシュ

Babylon で当たり判定（`checkCollisions` や物理エンジン）に使う簡易メッシュを、`scripts/add_box_collider.py` で作る。

- 元オブジェクトのローカル座標系でのバウンディングボックスと同じ大きさの箱を作り、`<元の名前>_collider` という名前で元オブジェクトの子にする。
- カスタムプロパティ `bjs_collider = True` が付く。Babylon 側ではこれを見て `isVisible = false` と `checkCollisions = true` を設定する。
- 箱で合わない形（L 字の壁など）は、箱を複数作るか、ユーザーと相談して専用の形を作る。
- 当たり判定の箱はリンク複製に含まれないので、複製ごとに作る必要がある。数が多い場合は、元のモジュールに作ってから複製するか、Babylon 側で生成する方法をユーザーに提案する。

## 5. タグ付け（Babylon へのメタデータ）

Babylon 側で特別に扱うオブジェクトには、`scripts/tag_objects.py` でカスタムプロパティを付ける。書き出し時に **Include → Custom Properties** を ON にすると、Babylon の `node.metadata.gltf.extras` から読める。

例:

| キー | 値の例 | 用途 |
|---|---|---|
| `bjs_role` | `"door"`, `"spawn"`, `"pickup"` | オブジェクトの役割 |
| `bjs_interactive` | `True` | クリック・タップの対象 |
| `bjs_collider` | `True` | 当たり判定用（`add_box_collider.py` が付ける） |

スポーン位置などの目印は、メッシュではなく Empty で置いてタグを付ける。

## 照明について

- 照明は原則として Babylon 側で置く（Babylon のライトとシャドウの設定を、コードでまとめて管理できるため）。
- Blender のライトを書き出す場合は、書き出し時に **Include → Punctual Lights** を ON にする（KHR_lights_punctual）。強さの単位は **Lighting Mode** によって変わる（既定の Standard は物理単位）。Babylon での見え方は Sandbox で確認する。
- ライトマップのベイクは hook で禁止されているため使えない。陰影を付けたい場合は、頂点カラーや Babylon 側のライティングで表現する。

## 次の工程

- マテリアル → `bjs-material`（モジュール間でマテリアルを共有すると、描画が軽くなる）
- 書き出す前 → `bjs-export-check`
