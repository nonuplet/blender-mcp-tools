# UV 展開

最初に `bjs-conventions` の SKILL.md を読む。形状の生成と仕上げ（`bjs-prop` / `bjs-environment`）が済んでから行う。

UV 展開は、オブジェクトの形とテクスチャの種類によってやり方が大きく変わる。自動の展開（Smart UV Project など）で済ませず、毎回方針を決めてから行う。

## 1. 方針を決める（確認ポイント）

次の内容をユーザーに確認する。

**テクスチャの種類**

| 種類 | 例 | UV の作り方 |
|---|---|---|
| なし | 単色、頂点カラーだけ | UV は不要（展開しなくてよい） |
| タイル状の模様 | 木目、板、タイル、布、コンクリート | **実寸に合わせて投影する**（このスキルの主な対象）。向きと縮尺をそろえ、模様が続く面は UV でもつなげる。UV は 0〜1 に詰めず、テクスチャの繰り返し（REPEAT）で敷き詰める |
| 1 枚絵 | ラベル、汚れ、手描きの絵 | seam を入れて Unwrap し、島を重ねずに 0〜1 に余白付きで詰める。今のところスクリプトはなく、ユーザーと手順を相談する |

**テクスチャの入手方法**

- コードで作れる模様（縞・市松・グラデーション・ざらつき）なら、`bjs-material` の `make_generated_texture.py` で作れる。
- それ以上の質感が必要な場合は、**無理に生成しない**。ユーザーに画像を用意してもらい、Blender に読み込んでもらう（Claude は画像の読み込みも Web からの取得もできない）。読み込み後は、`bjs-material` の `connect_image_texture.py` でマテリアルにつなぐ。

**面のグループごとの扱い（タイル状の模様の場合）**

向きや構造のある模様（縞・板・煉瓦・タイル・パネルなど）は、その構造がある面にしか合わない。面を次のグループに分けて、それぞれの扱いをデザインとして決める。

| グループ | 例 | 決めること |
|---|---|---|
| 側面 | 箱の 4 面、壁 | 模様の縮尺・向き・つながり |
| キャップ（最上部・最下部の水平な面） | 箱の上面・底面、壁の天端 | 側面と同じ模様を投影するか、テクスチャの 1 色だけを使うか、別のマテリアルにするか。**側面の模様を機械的に投影しない**（構造と模様が食い違い、角で色が中途半端につながる） |
| つなぎの面 | 面取り、溝の縁 | 原則、属する側面と同じ投影にする（スクリプトが自動で行う） |
| 途中の高さの水平な面 | 溝の上下の壁、段差 | 原則、近い側面に含める（スクリプトが自動で行う）。広い面（棚板、天板の裏など）はキャップとして扱う（`CAP_Z = "ALL"`） |

**タイル状の模様の場合に決めること**

- 縮尺: テクスチャ 1 枚（UV の 0〜1）を何 m にするか（`METERS_PER_TILE`）。模様の継ぎ目と形状の区切り（溝など）をそろえたい場合は、それに合わせて決める
- 向き: 側面の模様を水平にするか垂直にするか（`SIDE_ROTATE`）
- つながり: 側面をぐるりと 1 本につなげるか（`MODE = "WRAP"`。箱形向け）、面ごとに投影するか（`MODE = "BOX"`）
- キャップの扱い（上の表）

## 2. 面を確定する（確認ポイント）

UV は、その時点のメッシュの面に対して作られる。Bevel など**形を変えるモディファイア**を適用しないまま展開すると、モディファイアが作る面（面取りの面など）は隣の面の UV を補間した UV になり、模様が引き伸ばされる。

1. オブジェクトのモディファイアを確認し、形を変えるもの（Bevel / Mirror / Array / Solidify / Subdivision Surface など）を一覧にする。Smooth by Angle は面を変えないので対象外
2. **適用するかどうかを、毎回ユーザーに確認する。** 適用すると元に戻しにくく、パラメータ（面取りの幅など）を後から変えられなくなることも伝える
3. 了承を得たものだけ、`scripts/apply_modifiers.py` で適用する（`APPLY` にオブジェクト名とモディファイア名を明示する）

適用しない場合は、`uv_report.py`（`USE_EVALUATED = True`）で、モディファイアが作った面の歪みを確認する。

## 3. 展開する

### タイル状の模様: `scripts/uv_world_project.py`

| パラメータ | 内容 |
|---|---|
| `OBJECTS` | 対象オブジェクト |
| `MODE` | `"WRAP"`: 側面を正面（-Y）→ 右（+X）→ 背面（+Y）→ 左（-X）の順につなげる（箱形向け）／`"BOX"`: 面ごとに向いている軸で投影する |
| `METERS_PER_TILE` | テクスチャ 1 枚が何 m に相当するか |
| `SIDE_ROTATE` | 側面の模様の回転（0 / 90） |
| `OFFSET` | 模様の位置のずらし量（タイル単位） |
| `CAP_THRESHOLD` | 法線の Z 成分がこれ以上の面を「水平な面」とみなす（既定 0.9。45 度の面取りは側面になる） |
| `CAP_Z` | `"EXTREMES"`: 最上部・最下部の水平な面だけをキャップにする／`"ALL"`: 水平な面はすべてキャップ |
| `CAP_MODE` | キャップの UV。`"PROJECT"`: 上から投影（`CAP_ROTATE` で向き）／`"POINT"`: すべて `CAP_POINT` の 1 点（テクスチャの 1 色） |
| `CAP_MATERIAL_INDEX` | 整数なら、キャップの面にそのマテリアルスロット番号を割り当てる（別のマテリアルにする場合） |
| `UV_NAME` | 書き込む UV マップ（既存なら上書き） |

- 外側から見て U が右、V が上になる（模様が鏡像にならない）。
- 面取りなどの傾いた面は、自分の法線の水平成分で属する側面を決め、その側面と同じ投影になる。法線だけで「側面かキャップか」を決めると、45 度の面が同点になって分類が不定になり、キャップの模様が面取りに入り込む。
- 途中の高さの水平な面（溝の壁など）は、位置が最も近い側面に含める。投影方向と平行なので UV は線状に潰れ、その高さの模様の色が伸びる。細い面なら目立たないが、広い面なら `CAP_Z = "ALL"` でキャップとして扱う。
- `CAP_MATERIAL_INDEX` を使う場合は、その後 `bjs-material` で `SLOT_INDEX` に同じ番号を指定してマテリアルを割り当てる。マテリアルが分かれると、Babylon では子メッシュに分かれる（描画回数が増える）。
- 円柱や曲面、斜面が多い形は `WRAP` / `BOX` では歪む。その場合は seam を入れて Unwrap する方法をユーザーと相談する。

### 1 枚絵: seam と Unwrap

seam を入れる位置（目立たない辺）はオブジェクトごとに違うので、ユーザーと相談して決める。手順の目安は次のとおり。

- 編集モードで、seam にする辺に `bpy.ops.mesh.mark_seam()` を付ける
- `bpy.ops.uv.unwrap(method="ANGLE_BASED" / "CONFORMAL" / "MINIMUM_STRETCH", margin=...)` で展開する
- `bpy.ops.uv.pack_islands()` で 0〜1 に詰める（テクスチャの解像度に合わせて余白を取る）

Smart UV Project は、面どうしの角度で自動的に切り離し、島ごとに投影する方法。seam を使わないので速いが、島の向きと縮尺がそろわず、角をまたいで模様がつながらない。模様の向きが大事な場合には使わない。

## 4. 確認する（確認ポイント）

1. `scripts/uv_report.py` で数値を確認する

| 項目 | 見方 |
|---|---|
| `uv_per_meter_reference` | 歪みの基準。タイル状の模様なら `EXPECTED_UV_PER_METER = 1 / METERS_PER_TILE` を指定する（指定しなければ、面積で重み付けした中央値） |
| `distorted_faces` / `distorted_area_ratio` | 密度が基準から `DEVIATION`（既定 25%）以上ずれた面の数と面積比。45 度の面取りは約 16% 縮むので、既定値では出ない |
| `flipped_faces` | 裏返った UV（模様が鏡像になる）。0 であること |
| `collapsed_faces` / `collapsed_area_ratio` | UV が線や点に潰れた面（その面は単色に見える）。`CAP_MODE = "POINT"` のキャップと途中の高さの水平な面は意図どおり潰れる。それ以外で出たら原因を調べる |
| `islands` | 島の数。`WRAP` の箱なら少ないはず |
| `loops_outside_0_1` | 0〜1 の範囲外の割合。タイル状の模様なら問題ない。1 枚絵なら 0 であること |

2. マテリアルにテクスチャがあれば、`set_view.py`（`SHADING = "MATERIAL"`）でスクリーンショットを撮り、模様の向き・縮尺・つながりを見せる。まだなければ、`bjs-material` の後で確認する。特に、角・面取り・溝の縁で、模様が別の向きで入り込んでいないかを見る
3. UV エディターの画面を見せたい場合は、ユーザーの了承を得てから `jump_to_tab_by_name` で UV Editing ワークスペースに切り替え、`get_screenshot_of_area_as_image(area_ui_type="UV")` で撮る（ワークスペースを切り替えると、オブジェクトが編集モードになることがある）
